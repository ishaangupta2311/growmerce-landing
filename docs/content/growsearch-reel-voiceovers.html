Recording and edit notes

Use the headline of each script as its opening text overlay. Keep captions clear of the assistant’s answer, active filters, and product prices. The desktop wallpaper and browser chrome can be cropped where that leaves the full interaction visible.

Read at roughly 130–155 words per minute, with pauses for the on-screen actions. The scripts average about 100–145 words per minute across the full clip durations. Adjust the approximate cues to the recorded read. Keep the actual product reveal aligned with the matching spoken line.

For a shared closing prompt, overlay “Try the Growsearch demo · search.growmerce.ai” during the final seconds. If you want a spoken CTA, append a separate three-second end card: “See Growsearch in action. Try the demo.” That adds three seconds to the listed duration.

The short dashboard clips intentionally use short scripts. If you want a more detailed explanation, hold a relevant frame and extend the edit before recording a longer read. The source videos contain no voice-over; this deliverable is recording copy only.
