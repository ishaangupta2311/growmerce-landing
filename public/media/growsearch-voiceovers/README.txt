Growsearch voiceover edit package
=================================

Each model folder is divided into customer-side and merchant-side clips.
Inside each section:
- audio: 24 kHz mono WAV voice tracks, aligned to the original clip timeline
- review-video: the original picture with the matching voice track attached

Voice options:
- deepgram-flux-wade: Deepgram Flux TTS, Wade voice
- gemini-puck: Google Gemini 3.1 Flash TTS Preview, Puck voice

Files are numbered in the recommended review and edit order. Import a WAV at
00:00 beneath its matching source clip; all pauses are already included. The
cue-sheet.csv file lists the narration text and timing for every spoken beat.
